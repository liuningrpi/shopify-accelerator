# 🔧 WPS 开放平台权限配置详细指引

## ❌ 当前问题

虽然你说已经配置了权限，但测试结果显示：

```
"invalid_scope"
"The OAuth 2.0 Client is not allowed to request scope 'kso.sheets.read'."
```

**结论**: 应用还没有被授权使用表格读取权限。

## 📋 详细配置步骤

### 第1步：登录 WPS 开放平台

访问: **https://open.wps.cn/**

使用你创建应用时的账号登录。

---

### 第2步：进入应用管理

1. 登录后，找到 **"应用管理"** 或 **"我的应用"**
2. 在应用列表中找到你的应用：
   - **APP_ID**: `AK20251125ABNKZF`

---

### 第3步：查看应用类型 ⭐ 重要

点击应用进入详情页，确认**应用类型**：

#### 企业自建应用（推荐）
- ✅ 可以使用 client_credentials 授权
- ✅ 无需用户浏览器授权
- ✅ 适合服务器端自动化

#### 第三方应用
- ❌ 需要用户浏览器授权（authorization_code flow）
- ❌ 不适合纯后端自动化

**如果是第三方应用，需要重新创建"企业自建应用"！**

---

### 第4步：配置 API 权限

在应用详情页中，找到以下之一：
- **"API 权限"**
- **"权限管理"**
- **"接口权限"**
- **"高级设置"** → **"权限配置"**

#### 需要勾选的权限：

##### 必需权限（表格相关）：

查找并勾选以下权限（不同版本的平台可能名称略有不同）：

**选项 A: 金山文档在线表格（KSO）**
- ☑️ `kso.sheets.read` - 读取在线表格
- ☑️ `kso.sheets.readwrite` - 读写在线表格
- ☑️ `kso.sheets.meta` - 获取表格元数据

**选项 B: WPS 表格（ET）**
- ☑️ `et.read` - 读取 WPS 表格
- ☑️ `et.readwrite` - 读写 WPS 表格

**选项 C: 通用文件权限**
- ☑️ `file.read` - 读取文件
- ☑️ `file.readwrite` - 读写文件

##### 可选权限（文件列表）：
- ☑️ `kso.files.read` - 读取文件列表
- ☑️ `drive.read` - 读取网盘
- ☑️ `personal_files` - 个人文件访问

---

### 第5步：保存并提交审核

1. **勾选完权限后，点击"保存"或"提交"**

2. **重要：查看审核状态**
   - 某些权限可能需要**审核**
   - 审核状态会显示：
     - ✅ "已通过" / "已生效" - 可以使用
     - ⏳ "审核中" - 需要等待（1-3 个工作日）
     - ❌ "未通过" - 需要重新申请或联系技术支持

3. **如果需要审核，填写申请理由**：
   ```
   申请理由：用于企业内部自动化读取在线表格数据，实现数据同步和处理功能。
   使用场景：服务器端通过 API 读取金山文档在线表格，自动导出为 CSV 格式。
   ```

---

### 第6步：等待权限生效

- 有些权限立即生效
- 有些权限需要审核（通常 **1-3 个工作日**）
- 在审核通过前，无法使用这些权限

---

### 第7步：确认权限已生效

在应用详情页，检查权限状态：
- 所有勾选的权限旁边应该显示 **"已生效"** 或 **"✓"**
- 如果显示 **"审核中"**，需要继续等待

---

### 第8步：重新获取 Token

**只有在权限显示"已生效"后**，才执行以下步骤：

```bash
# 1. 删除旧 token
rm wps-sheet-reader/wps-token.json

# 2. 获取新 token
node wps-sheet-reader/get-access-token.js

# 3. 检查新 token 的权限
node wps-sheet-reader/check-token-scope.js

# 4. 测试读取表格
node wps-sheet-reader/read-sheet-api.js
```

---

✅ API 权限列表：
   - kso.sheets.read          [已生效]
   - kso.sheets.readwrite     [已生效]

如果配置正确，运行 `check-token-scope.js` 应该看到：

```

   ✅ 找到 scope: kso.sheets.read kso.sheets.readwrite kso.files.read
```

## ❓ 常见问题

### Q1: 找不到"API 权限"在哪里？

**A**: 不同版本的控制台位置可能不同：

1. 首页 → 我的应用 → 点击应用名 → 左侧菜单 → **"权限管理"**
2. 应用详情 → **"API 权限"** 标签
3. 应用详情 → **"高级设置"** → **"接口权限"**

如果还是找不到，**拍张截图**发给我，我帮你看。

---

### Q2: 权限列表里没有 kso.sheets.read？

**A**: 可能的原因：

1. **应用类型不对**
   - 只有"企业自建应用"或特定类型的应用才有表格权限
   - 解决：重新创建正确类型的应用

2. **权限名称不同**
   - 不同版本可能叫：
     - "在线表格读取权限"
     - "WPS 表格 API"
     - "轻维表读写"
   - 解决：找类似名称的权限勾选

3. **需要单独申请**
   - 某些高级权限需要单独申请开通
   - 解决：联系技术支持 open@wps.cn

---

### Q3: 权限一直显示"审核中"怎么办？

**A**:

- 通常 1-3 个工作日内会审核
- 超过 3 个工作日还在审核：
  - 发邮件给 open@wps.cn
  - 提供 APP_ID 和申请时间
  - 要求加快审核

---

### Q4: 我是企业自建应用，还需要审核吗？

**A**:

- **基础权限**（如 file.read）: 通常不需要审核，立即生效
- **敏感权限**（如 sheets.readwrite）: 即使是企业应用，首次申请可能也需要审核
- 具体看平台提示

---

### Q5: 审核不通过怎么办？

**A**:

查看审核驳回理由：
- 如果是"使用场景不明确"：重新申请时详细说明用途
- 如果是"应用类型不符"：可能需要创建不同类型的应用
- 如果是"权限过高"：尝试只申请最小必要权限（如只申请 read，不申请 readwrite）
